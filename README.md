        O projeto utiliza versão 3.12 do Python, mas versões mais antigas podem funcionar.

O primeiro passo é executar "pip install -r requeriments.txt"

--Você provavelmente vai precisar do Visual Studio Build Tools para compilar algumas dependências. 
Você pode baixar ele aqui: https://visualstudio.microsoft.com/visual-cpp-build-tools/


O arquivo teste.py serve para você ver se a biblioteca principal está funcionando.
